# Jens Web 改造文档集

## 1. 文档状态

- 状态：需求与总体设计基线
- 用途：指导后续 Web 平台和本地 Agent 的设计、开发、测试与验收
- 当前范围：仅文档，不包含任何实现代码或依赖变更
- 依据：现有 Jens 项目结构、`docs/改造回答.txt`、`docs/改造回答2.txt` 及后续确认

## 2. 核心目标

将当前“每位用户复制完整项目并使用 Qt 页面”的模式改造为：

```text
中心 Web 平台 + 用户浏览器 + 用户本地精简 Agent
```

中心平台负责账号、共享任务库、Step 发布、任务下发、运行状态和最近20条执行记录。Agent 在用户本地调用现有 Jens Runner 和 Airtest，操作本机 CrealityScan。

## 4. 推荐阅读顺序

1. 产品、测试和开发共同确认 `00` 与 `01`；
2. 后端和 Agent 开发确认 `02`、`04`、`05`；
3. Web 页面开发确认 `03`；
4. 部署和管理员确认 `06`；
5. 项目负责人根据 `07` 拆分迭代；
6. 全员在实施前复核 `08` 中的风险。

## 5. 变更管理

以下变化必须先更新文档，再进入实现：

- 一个账号允许绑定多台 Agent；
- 普通用户可以修改其他用户创建的任务；
- 增加网页远程停止或暂停恢复；
- 允许普通用户上传 Python Step；
- 执行记录不再限制为每用户最近20条；
- Agent 改为 Windows Service 执行 Airtest；
- Web 服务对互联网开放；
- Qt 平台停止维护。
