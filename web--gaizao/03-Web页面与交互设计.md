# Web 页面与交互设计

## 1. 设计原则

- 面向重复操作，页面保持安静、紧凑、可扫描；
- 首屏直接进入任务与运行工作区，不制作营销落地页；
- 使用清晰状态而不是让用户从日志猜测结果；
- 重要操作必须显示当前 Agent 是否可执行；
- 不在页面中暴露 Python 文件路径和内部模块细节；
- 所有权限由服务端再次校验，不能只依赖按钮隐藏。

## 2. 页面结构

```text
登录
└─ 主工作区
   ├─ 任务库
   ├─ 新建/编辑任务
   ├─ 当前运行
   ├─ 执行记录
   ├─ 我的 Agent
   ├─ 修改密码
   └─ 管理后台（仅管理员）
      ├─ 用户管理
      ├─ 全部任务
      ├─ Agent 状态摘要
      ├─ Step 发布
      └─ 系统与审计
```

## 3. 全局布局

建议采用桌面优先的工作台布局：

- 顶部栏：产品名、Agent 状态、当前用户、退出；
- 左侧导航：任务库、当前运行、执行记录、我的 Agent；
- 主内容区：当前页面；
- 运行任务时顶部持续显示状态条，但不遮挡操作。

Agent 状态使用固定语义：

| 状态 | 显示 | 可执行 |
| --- | --- | --- |
| 在线空闲 | 绿色状态图标 + 在线空闲 | 是 |
| 运行中 | 蓝色状态图标 + 当前任务 | 否 |
| 离线 | 灰色状态图标 + 最后在线时间 | 否 |
| 环境异常 | 红色状态图标 + 简短原因 | 否 |
| 未绑定 | 警告状态 + 绑定入口 | 否 |

## 4. 登录页面

字段：

- 用户名；
- 密码；
- 登录按钮。

行为：

- 登录失败使用统一错误提示，不暴露账号是否存在；
- 连续失败触发短时限制；
- 已登录用户访问登录页时跳转任务库；
- 不提供开放注册；
- 忘记密码由管理员重置。

## 5. 任务库

### 5.1 列表字段

- 任务名称；
- 创建人；
- Step 数量；
- 最近更新时间；
- 是否由自己创建；
- 操作。

### 5.2 筛选

- 名称搜索；
- 创建人；
- 设备或模组；
- 任务类型；
- 仅看我创建。

### 5.3 操作权限

| 操作 | 自己任务 | 他人任务 | 管理员 |
| --- | --- | --- | --- |
| 查看 | 是 | 是 | 是 |
| 执行 | 是 | 是 | 是 |
| 复制 | 是 | 是 | 是 |
| 编辑 | 是 | 否 | 是 |
| 删除 | 是 | 否 | 是 |

没有权限的操作不显示；服务端仍必须拒绝绕过页面发起的请求。

### 5.4 执行按钮状态

- Agent 在线空闲：按钮可用；
- Agent 运行中：按钮禁用并显示当前任务；
- Agent 离线：按钮禁用并提供 Agent 页面入口；
- Agent 环境异常：按钮禁用并显示异常详情；
- 未绑定：按钮禁用并提示先绑定。

## 6. 任务编排页面

### 6.1 布局

```text
┌──────────────┬────────────────────────┬──────────────────┐
│ Step 库      │ 已选择 Step            │ 当前 Step 参数   │
│ 搜索/分类    │ 顺序/名称/状态策略      │ preset/params    │
└──────────────┴────────────────────────┴──────────────────┘
```

不要求首版实现拖拽。可以使用上移、下移按钮保证稳定性和可访问性。

### 6.2 Step 库

- 显示 Step 名称、ID 和版本；
- 支持名称和 ID 搜索；
- 按领域分类；
- 只显示管理员启用的版本；
- 同一 Step 多版本时默认推荐版本，但任务可以保留旧版本。

### 6.3 参数编辑

- 有 preset 时使用下拉选择，不要求用户编辑内部 key；
- 布尔值使用复选框或开关；
- 数值使用带范围校验的输入框；
- 枚举使用下拉菜单；
- 未结构化的遗留参数提供 JSON 高级编辑区；
- JSON 错误必须阻止保存并定位问题。

### 6.4 保存和所有权

- 新建任务的所有者为当前用户；
- 复制任务生成新 ID，并将所有者设为当前用户；
- 编辑他人任务时只能“复制为我的任务”；
- 保存时使用版本号防止覆盖并发修改；
- 删除前显示任务名称并二次确认。

## 7. 当前运行页面

### 7.1 顶部摘要

- 任务名称；
- Agent 名称与状态；
- 开始时间；
- 已运行时间；
- 当前步骤；
- 完成步骤数/总步骤数；
- 最终状态。

网页不提供停止按钮。页面应明确提示紧急停止只能在用户电脑的 Agent 小窗口执行。

### 7.2 步骤明细

每个 Step 使用固定高度行展示：

- 序号；
- 名称；
- 状态；
- 尝试次数；
- 耗时；
- 错误摘要；
- 截图入口。

状态：等待、执行中、重试中、通过、失败、本地停止、跳过。

### 7.3 日志窗口

- 使用等宽字体；
- 显示时间和来源；
- 区分 Runner、Agent 和系统消息；
- 支持自动滚动开关；
- 支持搜索；
- 支持下载完整日志；
- 浏览器只保留有限行数，完整内容保存在服务器文件；
- 连接断开时显示状态，不清空已有内容；
- 重连后根据最后事件序号补齐。

## 8. 执行记录

每个用户只显示自己的最近20条记录。

列表字段：

- 任务名称；
- 状态；
- Agent；
- 开始和结束时间；
- 总耗时；
- 失败步骤；
- 详情入口。

管理员可以查看所有用户的运行摘要，但管理员页面不提供打开普通用户原始 CrealityScan 日志内容的入口。

## 9. 运行详情

- Task JSON 快照；
- Step 版本快照；
- 步骤结果；
- 错误堆栈；
- 失败截图；
- `result.json`；
- `summary.json`；
- `report.html`；
- Runner 日志；
- 当前用户自己的原始 CrealityScan 日志。

如果服务器记录已因20条策略被清理，旧链接返回明确的“记录已过保留期”，不能泄漏文件路径。

## 10. 我的 Agent

未绑定时：

- 绑定码输入；
- 绑定说明；
- Agent 安装包下载；
- 服务器地址展示。

已绑定时：

- Agent 名称；
- 在线状态；
- Agent 版本；
- Step 缓存版本摘要；
- 最后心跳；
- 当前任务；
- 分辨率、缩放比例、CrealityScan 状态；
- 解除绑定操作。

解除绑定必须二次确认。运行中不允许解除绑定。

## 11. 管理后台

### 用户管理

- 创建、编辑、禁用、启用和删除普通用户；
- 重置密码；
- 查看账号是否绑定 Agent；
- 删除用户前处理其任务所有权和执行记录。

### Step 发布

- 上传受信任 Step 包；
- 显示版本、哈希、兼容 Agent 版本和发布人；
- 启用或停用版本；
- 禁止覆盖已有同版本内容。

### 系统状态

- 在线 Agent 数量；
- 运行中 Agent 数量；
- Web 服务版本；
- 服务器存储使用量；
- 最近异常；
- 审计记录。

## 12. 错误与空状态

- Agent 离线：说明最后在线时间和启动 Agent 的动作；
- CrealityScan 未启动：说明需要在用户电脑启动；
- 本地执行锁占用：说明 Qt、Agent 或手动 Runner 正在执行；
- Step 下载失败：显示可重试错误，不启动 Runner；
- 无任务：提供新建任务与复制任务入口；
- 无执行记录：不显示装饰性空卡片，仅显示简洁空状态。
