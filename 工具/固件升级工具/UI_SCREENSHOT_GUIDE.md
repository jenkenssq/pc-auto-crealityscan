# UI元素截图指南

本文档指导如何截取CrealityScan应用的UI元素图片，用于Airtest图像识别。

## 截图工具

推荐使用Windows自带的截图工具：
- 快捷键：`Win + Shift + S`
- 或使用Snipping Tool

## 截图原则

1. **只截取目标元素**：不要包含过多背景
2. **保持清晰**：确保文字和图标清晰可见
3. **适中大小**：不要太大也不要太小
4. **PNG格式**：保存为PNG格式以保持质量

## 截图步骤示例

以截取"新建项目"按钮为例：

1. 启动CrealityScan应用
2. 等待应用完全加载到首页
3. 按下 `Win + Shift + S` 启动截图工具
4. 用鼠标框选"新建项目"按钮
5. 截图会自动复制到剪贴板
6. 打开画图工具（mspaint）或其他图片编辑器
7. 粘贴（Ctrl + V）
8. 另存为PNG格式到 `resources/images/home/new_project.png`

## 验证截图质量

截图完成后，可以通过以下方式验证：

1. 打开图片，确保清晰可见
2. 图片大小适中（通常50x50到200x200像素之间）
3. 背景干净，没有多余元素
4. 如果是按钮，确保边框完整

## 调试技巧

如果测试时识别失败：

1. **降低识别阈值**：在 `app_config.yaml` 中将 `threshold` 从 0.85 降到 0.75
2. **重新截图**：确保截图时应用窗口大小和测试时一致
3. **检查分辨率**：不同分辨率可能导致识别失败
4. **使用更大的截图**：包含更多上下文信息

## 注意事项

1. **保持一致性**：所有截图应在相同的显示设置下完成
2. **避免动画**：等待动画完成后再截图
3. **按钮状态**：确保按钮处于正常状态（非禁用、非悬停）
4. **文件命名**：严格按照文档中的文件名保存
