# 修复升级确认对话框点击问题

## 问题现象
程序日志显示"成功点击确定按钮"，但实际上升级确认对话框（"立即升级？"）仍然显示，确定按钮没有被真正点击。

## 问题原因
通用的"确定"按钮图片可能与升级确认对话框的"确定"按钮样式不匹配，导致：
1. 图像识别失败
2. 或者点击到了错误的位置

## 解决方案

改进 `_confirm_upgrade()` 方法，使用四层备用方案：

### 方法1: 专用升级确认按钮图片
尝试使用专门为升级确认对话框截取的按钮图片。

### 方法2: 通用确定按钮图片
使用通用的确定按钮图片（原有方法）。

### 方法3: pywinauto 查找按钮（新增）
```python
from pywinauto import Desktop

desktop = Desktop(backend="uia")

# 查找升级对话框
dlg = desktop.window(title_re=".*升级.*")

# 查找确定按钮
for btn_text in ["确定", "确认", "OK", "Yes"]:
    try:
        btn = dlg.child_window(title=btn_text, control_type="Button")
        btn.click()
        break
    except:
        continue
```

**优势**：
- 通过文本查找按钮，不依赖图像识别
- 支持多种按钮文本（确定、确认、OK、Yes）
- 更可靠

### 方法4: 按回车键（新增）
```python
text("\n")  # 按回车
```

**原理**：
- 很多对话框的默认按钮（通常是蓝色高亮的）可以用回车键触发
- 从截图看，"确定"按钮是蓝色的，应该是默认按钮
- 直接按回车应该能触发

## 推荐操作

### 选项A: 截取升级确认按钮图片（推荐）
1. 手动触发升级流程，让"立即升级？"对话框出现
2. 截取"确定"按钮的图片
3. 保存为 `resources/images/settings/upgrade_confirm.png`

这样方法1就能工作，是最可靠的方式。

### 选项B: 依赖自动备用方案
如果不想截图，程序会自动尝试方法3和方法4：
- 方法3会通过文本查找"确定"按钮
- 方法4会直接按回车键
