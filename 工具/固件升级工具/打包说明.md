# CrealityScan 自动化测试工具 - Windows 打包说明

## 快速开始

### 方式一：双击打包（推荐）

1. 双击运行 `打包.bat`
2. 等待打包完成
3. 在 `dist\CrealityScan自动化测试工具\` 目录中找到 `CrealityScan自动化测试工具.exe`

### 方式二：命令行打包

```bash
# 安装依赖
pip install -r requirements.txt
pip install pyinstaller

# 执行打包
python build_exe.py
```

## 打包输出

```
dist\
└── CrealityScan自动化测试工具\
    ├── CrealityScan自动化测试工具.exe    # 主程序
    ├── config\                           # 配置文件
    ├── resources\                        # 资源文件（图片等）
    └── ...其他依赖文件
```

## 使用打包后的程序

1. 将整个 `CrealityScan自动化测试工具` 文件夹拷贝到目标电脑
2. 无需安装 Python 环境
3. 双击 `CrealityScan自动化测试工具.exe` 运行

## 注意事项

### 1. 首次运行需要配置

如果是首次在目标电脑运行，可能需要：

- 配置 CrealityScan 软件路径
- 配置日志目录
- 确保模板图片路径正确

### 2. 依赖文件

打包后的程序依赖以下文件，请确保不要删除：

- `config/` 目录 - 配置文件
- `resources/` 目录 - UI 模板图片

### 3. 如果运行出错

1. 检查是否完整拷贝了整个文件夹
2. 查看同目录下的 `*.log` 日志文件
3. 错误日志可能输出到控制台，按需添加 `pause` 保留窗口

## 自定义配置

打包后可编辑 `config\app_config.yaml` 修改：

```yaml
app:
  exe_path: "D:\\CrealityScan\\CrealityScan.exe"  # 软件路径
  log_dir: "C:\\Users\\用户名\\AppData\\Local\\Creality\\CrealityScan\\Logs"  # 日志目录

image_recognition:
  threshold: 0.85  # 图像识别阈值
```

## 重新打包

如果修改了代码或配置：

1. 重新运行 `python build_exe.py`
2. 将 `dist` 目录下的内容重新拷贝到目标电脑

## 常见问题

### Q: 打包后体积太大怎么办？

A: Airtest 框架包含较多依赖，体积约 200-300MB 属于正常范围。可以尝试：
- 使用 `--exclude-module=testcases` 排除测试用例
- 使用 UPX 压缩

### Q: 目标电脑运行时提示缺少 DLL？

A: 可能需要安装 Visual C++ Redistributable:
https://aka.ms/vs/17/release/vc_redist.x64.exe

### Q: 如何添加桌面快捷方式？

A: 可以手动创建快捷方式，指向 `CrealityScan自动化测试工具.exe`
