# CrealityScan 自动化测试工具 - 部署说明

## 当前状态

由于 Python 3.10 与 PyInstaller 存在 bytecode 兼容性问题（IndexError: tuple index out of range），暂时无法成功打包成单个 exe 文件。

## 替代方案：便携式部署

### 步骤 1：拷贝整个项目文件夹

将 `固件升级自动化` 整个文件夹拷贝到目标电脑。

### 步骤 2：运行部署脚本

双击运行 `部署.bat`，按提示完成依赖安装：

```
部署.bat
```

### 步骤 3：启动程序

双击 `启动测试工具.bat` 启动程序。

---

## 手动部署（不使用虚拟环境）

如果目标电脑已有 Python 3.10 环境：

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行程序
python run_test.py
```

---

## Python 打包问题说明

### 问题原因

Python 3.10 引入的 bytecode 格式变化与 PyInstaller 的模块分析器存在兼容性问题，导致在分析某些模块时出现 `tuple index out of range` 错误。

### 可能的解决方案

1. **使用 Python 3.9** - 推荐，在 Python 3.9 环境下打包
2. **等待 PyInstaller 更新** - 关注 PyInstaller 最新版本
3. **使用虚拟环境** - 在 Python 3.9 的虚拟环境中打包

### 使用 Python 3.9 打包

```bash
# 1. 安装 Python 3.9
# https://www.python.org/downloads/

# 2. 使用 Python 3.9 创建虚拟环境
py -3.9 -m venv venv39
call venv39\Scripts\activate.bat

# 3. 安装依赖
pip install -r requirements.txt

# 4. 打包
pyinstaller run_test.py --name=CrealityScan自动化测试工具 --onedir --windowed
```
