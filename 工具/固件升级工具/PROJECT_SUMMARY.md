# 项目交付文档

## 项目概述

**项目名称**：CrealityScan固件升级自动化测试框架
**技术栈**：Python + Airtest + PyWinAuto
**目标平台**：Windows（后续支持Mac）
**测试对象**：CrealityScan三维扫描软件
**核心功能**：自动化测试固件升级前后的开流功能

## 测试流程设计

```
开始
  ↓
连接Windows设备
  ↓
启动CrealityScan
  ↓
【第一次开流】
  ├─ 点击新建项目
  ├─ 确认弹窗
  ├─ 点击预览
  ├─ 点击扫描
  └─ 验证开流成功
  ↓
【固件升级】
  ├─ 点击设置
  ├─ 点击设备管理
  ├─ 选择固件文件
  ├─ 确认升级
  ├─ 等待升级完成
  └─ 验证设备重连
  ↓
【第二次开流】
  ├─ 重复开流流程
  └─ 验证功能正常
  ↓
生成测试报告
  ↓
结束
```

## 技术亮点

1. **模块化设计**：核心功能独立封装，易于维护和扩展
2. **配置驱动**：通过YAML配置文件灵活控制测试行为
3. **图像识别**：基于Airtest的图像识别技术，适应不同UI
4. **日志系统**：彩色日志输出，清晰的测试步骤追踪
5. **异常处理**：完善的错误处理和日志记录
6. **可扩展性**：易于添加新的测试用例和功能模块

## 使用指南

### 环境准备

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置应用路径
# 编辑 config/app_config.yaml

# 3. 准备UI截图
# 参考 UI_SCREENSHOT_GUIDE.md

# 4. 检查环境
python check_env.py
```

### 运行测试

```bash
python run_test.py -f resources/firmware/your_firmware.bin
```

### 查看结果

- 控制台：实时输出
- 日志：`logs/test_YYYYMMDD_HHMMSS.log`
- 截图：`screenshots/`

## 关键注意事项

1. **首次运行前必须准备UI截图**，否则无法识别界面元素
2. 测试过程中不要操作鼠标键盘
3. 确保CrealityScan应用未运行，框架会自动启动
4. 固件升级时间较长，请耐心等待
5. 如果识别失败，调整 `app_config.yaml` 中的 `threshold` 值
