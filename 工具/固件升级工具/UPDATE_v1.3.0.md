# v1.3.0 更新说明 - 开流验证和帧数监控

## 更新日期
2026-03-12

## 更新概述
完善开流验证逻辑，新增点云渲染检查和帧数监控功能。

## 主要更新

### 1. 开流验证逻辑完善 ✨

#### 三重验证机制
开流验证现在包含三个检查项：

1. **点云渲染验证** ✨新增
   - 检查扫描页是否有点云渲染
   - 确保点云正常显示

2. **IR相机验证**
   - 检查IR相机窗口是否正常出流
   - 必需验证项

3. **彩色相机验证**（动态）
   - 通过日志判断是否需要验证
   - 如果当前模式有彩色视窗，则验证彩色相机
   - 如果没有彩色视窗，则跳过此验证

#### 验证流程
```
点击扫描
    ↓
等待渲染（5秒）
    ↓
验证点云渲染 ✨
    ↓
验证IR相机
    ↓
判断是否有彩色视窗（通过日志）
    ↓
验证彩色相机（如果有）
    ↓
开流验证成功
```

### 2. 帧数监控功能 ✨

#### 智能等待机制
在点击"完成扫描"按钮之前，框架会：
- 实时监控日志文件中的帧数信息
- 等待帧数达到目标值（默认100帧）
- 达到目标帧数后才执行完成扫描操作

#### 帧数监控逻辑
```python
# 支持多种日志格式
frame_patterns = [
    r'帧数[:\s]+(\d+)',           # "帧数: 50"
    r'Frame[:\s]+(\d+)',           # "Frame: 50"
    r'当前帧[:\s]+(\d+)',          # "当前帧: 50"
    r'frame\s+count[:\s]+(\d+)',   # "frame count: 50"
    r'frames[:\s]+(\d+)',          # "frames: 50"
]
```

#### 返回首页流程（更新后）
```
开流验证成功
    ↓
监控日志，等待帧数达到100帧 ✨新增
    ↓
点击"完成扫描"按钮
    ↓
点击"返回首页"按钮
    ↓
点击"确定"按钮
    ↓
返回首页成功
```

### 3. 配置文件更新

#### app_config.yaml 新增配置项

```yaml
# 操作超时配置
timeouts:
  frame_count_wait: 120  # 帧数监控超时时间（秒）

# 扫描配置
scan:
  target_frames: 100  # 完成扫描前需要达到的目标帧数
```

**配置说明**：
- `frame_count_wait`: 等待帧数的最长时间，超时后会继续执行完成扫描
- `target_frames`: 目标帧数，可以根据实际需求调整（如50帧、200帧等）

### 4. 代码结构优化

#### StreamHandler 新增方法

1. **`_verify_point_cloud_rendering()`** - 验证点云渲染
   - 检查点云是否正常渲染
   - 可通过UI图像识别或日志验证

2. **`_verify_ir_camera()`** - 验证IR相机
   - 检查IR相机窗口是否出流
   - 可通过UI图像识别或日志验证

3. **`_verify_color_camera()`** - 验证彩色相机
   - 检查彩色相机窗口是否出流
   - 仅在有彩色视窗时调用

4. **`_wait_for_frame_count()`** - 等待帧数达到目标值
   - 实时监控日志文件
   - 提取帧数信息
   - 达到目标后返回

## 使用指南

### 配置目标帧数

编辑 `config/app_config.yaml`：

```yaml
scan:
  target_frames: 100  # 修改为你需要的帧数
```

### 配置超时时间

```yaml
timeouts:
  frame_count_wait: 120  # 修改为合适的超时时间
```

### 日志格式要求

框架会在日志中查找帧数信息，支持以下格式：
- `帧数: 50`
- `Frame: 50`
- `当前帧: 50`
- `frame count: 50`
- `frames: 50`

**如果你的日志格式不同**，可以在 `core/stream_handler.py` 中的 `_wait_for_frame_count()` 方法中添加自定义的正则表达式。

### 自定义帧数正则表达式

```python
frame_patterns = [
    r'帧数[:\s]+(\d+)',
    r'Frame[:\s]+(\d+)',
    r'你的自定义格式',  # 添加你的格式
]
```

## 容错机制

### 帧数监控失败时
- 如果未配置日志文件路径：等待30秒后继续
- 如果日志格式不匹配：等待超时后继续
- 如果监控超时：记录警告并继续执行完成扫描

### 开流验证失败时
- 点云渲染验证失败：测试终止
- IR相机验证失败：测试终止
- 彩色相机验证失败：测试终止

## 性能影响

### 时间估算更新

| 阶段 | 之前 | 现在 | 说明 |
|------|------|------|------|
| 开流验证 | 5秒 | 5秒 | 无变化 |
| 等待帧数 | 0秒 | 10-120秒 | 新增，取决于扫描速度 |
| 完成扫描 | 立即 | 达到100帧后 | 更准确 |
| **总计** | 30-60秒 | 40-180秒 | 增加了帧数等待时间 |

**注意**：实际时间取决于：
- 扫描速度（帧率）
- 目标帧数设置
- 是否配置了日志路径

## 已知限制

1. **日志格式依赖**：需要日志中包含帧数信息
2. **正则表达式匹配**：默认正则可能不适用所有日志格式
3. **超时处理**：超时后会继续执行，可能导致帧数不足

1. 降低目标帧数（如改为50帧）
2. 增加超时时间
3. 检查扫描是否正常进行
