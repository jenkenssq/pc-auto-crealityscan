# 任务：将「CrealityScan 后处理对比工具」重构为 macOS 版

你是自动化测试工程专家，请在 macOS 上把 Windows 版「CrealityScan 后处理对比平台/工具」重构为可运行的 macOS 版。
Windows 版依赖 `Airtest(Windows 桌面)`、`pywinauto`、`ctypes.windll`，在 macOS 上**不可用**。
你必须在保留功能规格的前提下，用 `PyAutoGUI`（找图/点击/截图）+ `AppleScript / System Events`（文件对话框）+ `psutil`（进程管理）+ `openpyxl`（对比表）等跨平台/原生手段重新实现。

> 本目录里已经放好了全部参考材料（源码、步骤、模板图、已验证的 Mac 自动化原型），先把它们读完再动手。

## 二、功能规格（需求合同，逐条对照 Windows 版实现，不可省略）

1. **对比类型**：一次任务必须且只能选择一种后处理，四种二选一：
   | 参数值 | 名称 | 默认超时 |
   | --- | --- | ---: |
   | `texture` | 贴图 | 90s |
   | `gaussian` | 高斯渲染 | 900s |
   | `ai_retexture` | AI重贴图 | 600s |
   | `human_body_completion` | 人体补全 | 600s |
2. **双版本串行**：固定顺序「发布版全部工程 → 关闭发布版 →（可选删下载包）→ 测试版全部工程 → 关闭测试版」，**两个版本绝不能同时运行**。
3. **工程集批量**：工程集可直接含 `project.obp`，或在一级子目录含多个 `project.obp`；按路径排序，每个工程输出带序号（`工程1_…`、`工程2_…`）。
4. **工作副本隔离**：每个原始工程必须复制为发布版、测试版两份独立副本（校验磁盘空间、禁止覆盖已存在目录、失败自动清理重试 2 次）；**原始工程绝不直接导入/修改**。
5. **每个版本的流程**：创建副本 → 启动 CrealityScan → 导入工程 → 等待导入成功日志 → 执行选定后处理 → 等待完成 → 保存全屏截图+耗时 → 返回首页 → 点击确认后固定等 3 秒。
6. **完成判定**：
   - 导入工程：日志出现 `OB_SCAN_MESSAGE_ID_PROJECT_IMPORT_SUCCESS` **或** `i proj progress 1.000000`（任一命中即成功），只匹配点击导入之后的新增内容；默认超时 600s，轮询间隔 0.2s。
   - 各后处理：按对应模板/进度条“出现→消失”判定完成并记录耗时。
7. **测试版缺包自动下载**：人体补全/AI重贴图/高斯渲染，当「测试版 + 本地无对应下载包 version.txt」时，自动点击 CrealityScan 的“下载”弹窗按钮并等待下载完成：
   - 高斯渲染 → `AITextureRestore/version.txt`，弹窗出现在点击“应用”之后；
   - 人体补全 → `AIBodyComplete/version.txt`，弹窗在点击“AI人体补全”之后；
   - AI重贴图 → `AITextureRestore/version.txt`，弹窗在点击“AI重贴图”之后。
   - 下载进度从 `app.log` 解析 `Download progress: xx%` 用于日志展示；下载超时默认 1800s。
8. **发布后删除下载包（可选开关）**：默认不删；开启后在发布版全部完成后删除对应 `<包名>` 及 `<包名>_Data` 目录，触发测试版重新下载。CLI 参数 `--delete-download-package`。
9. **截图留证**：后处理完成后全屏截图；截图前把鼠标移到安全位置（默认 (10,10)）等 0.3s 再截图，避免 hover 高亮。
10. **运行日志**：本次运行完整 stdout/stderr 同时写入输出目录 `运行日志.txt`；长等待每 30s 打一次心跳（已等待/上限）。
11. **对比表**：两个版本全部完成后生成对比表，发布版/测试版截图并排、按工程序号嵌入；表头附带下载包版本号（读取不到显示“未获取”）；截图缺失/数量异常在对应行明确标记。Windows 版用 `.xlsx`（openpyxl），Mac 版可沿用 `.xlsx` 或改用 HTML，**但必须保留“并排+序号+缺失标记+包版本”的信息内容**。
12. **结果目录**：每次任务创建时间戳目录 `compare_YYYYmmdd_HHMMSS_ffffff/`，内含 `release/`、`test/`、`运行日志.txt`、对比表。
13. **紧急停止**：中断时关闭当前 CrealityScan、终止进程树；退出码约定：`0` 全部完成 / `1` 至少一侧失败 / `2` 配置无效或副本准备失败 / `3` 用户中断。

## 三、CLI 参数合同（Mac 版至少支持这些；路径从 `.exe` 改为 `.app` 或可执行文件）

```
--operation texture|gaussian|ai_retexture|human_body_completion   (必填)
--release-app/--release-exe    发布版 CrealityScan（.app 或可执行文件路径）
--release-version              发布版版本标识
--test-app/--test-exe          测试版 CrealityScan
--test-version                 测试版版本标识
--project-set                  原始工程集目录
--output-dir                   对比结果根目录
--operation-timeout            覆盖当前操作默认超时
--texture-timeout              默认 90
--gaussian-timeout             默认 900
--ai-retexture-timeout         默认 600
--human-body-completion-timeout 默认 600
--gaussian-quality 快速|标准|高质量  默认 高质量
--ai-retexture-gaussian        开启高斯渲染
--no-texture-first             AI重贴图前不先执行贴图（默认先执行）
--human-body-hd-geometry       开启超清几何精度
--base-wait                    默认 20
--skip-trip-model             人体补全不生成trip，直接生成人体补全模型
--start-timeout                默认 120
--close-timeout                默认 20
--delete-download-package      发布后删除下载包
--test-only                    只跑测试版
--log-dir                      日志根目录（覆盖自动探测）
```

校验规则（沿用 Windows 版）：
- `--operation` 必填，否则退出码 2；
- 发布版与测试版不能是同一路径；
- 输出目录不能位于工程集内部；
- 发布版和测试版 EXE/APP 路径必须存在。

## 四、四个后处理步骤的移植规格（模板/坐标/动作/等待）

模板图都在 `reference/pc_tool/setps/<step>/v1_0_0/templates/`，请原样拷贝进 Mac 工程。以下 `record_pos/resolution` 是 Windows Airtest 的相对坐标定义，**PyAutoGUI 找图不需要它**（`locateCenterOnScreen` 直接返回实际像素坐标）；但**固定坐标点击**必须按屏幕分辨率处理（见“五、macOS 适配”）。

### 1) import_project（导入工程）
- 动作：点 `tpl1772543115770.png` → 点 `tpl1772543123954.png` → 打开文件对话框 → 输入 `project.obp` 完整路径 → 点“打开”。
- 文件对话框（Windows 用 pywinauto 控制 #32770）：Mac 上改用 AppleScript `System Events`（详见五）。
- 等待：日志关键字（见功能规格 6），成功返回 `success_marker / success_log_file / import_elapsed_sec`。
- 参数：`project_file_path / click_delay_sec(1.0) / dialog_timeout_sec(15) / log_dir / import_success_timeout_sec(600) / poll_interval_sec(0.2)`。
- 日志根目录 Windows 默认 `%LOCALAPPDATA%\Creality\CrealityScan\Logs`；Mac 版默认路径请在真机确认（优先 `~/Library/Logs/Creality/CrealityScan` 或 `~/Library/Application Support/Creality/CrealityScan/Logs`），并允许 `--log-dir` 覆盖。

### 2) texture_operation（贴图）
- 动作：`touch((160,285))` → 点 `tpl1774270225446.png` → 点 `tpl1772613788279.png` → 等 `tpl1772613816094.png` 出现 → 等它消失（超时 `timeout_sec`，默认 90）→ 鼠标复位 → 全屏截图。
- 返回 `snapshot / operation_elapsed_sec / operation_elapsed_label`。
- 注意：Windows 用 `ctypes.windll.user32.SetCursorPos` 复位鼠标，Mac 用 `pyautogui.moveTo(10,10)`。

### 3) gaussian_rendering（高斯渲染）
- 动作：点 `tpl1774270225446.png` → 点 `tpl1786174242991.png` → 质量选择（默认“高质量”已选中不用点；选“快速”点 (70,220)、“标准”点 (180,220)）→ 点 `tpl1786174282206.png`（应用）→（测试版缺包时处理下载弹窗）→ 等 `tpl1786174502310.png` 进度条出现→消失（超时 900）。
- 参数：`timeout_sec / gaussian_quality`。

### 4) ai_retexture_operation（AI重贴图）
- 前置：默认先完整执行一次贴图（独立超时 `texture_timeout_sec`=90）；`--no-texture-first` 可关。
- 动作：点 `tpl1774270225446.png` → 点 `tpl1786450964565.png` →（测试版缺包处理下载弹窗）→ 等 `dialog_wait_sec`(5s) → 点 `tpl1786451671324.png` → 在 “Select Texture Images” 弹窗导入 `img/` 目录图片（单图：填完整路径直接打开；多图：导航进目录后全选）→ 等 `tpljindutiao.png` 进度条 → 可选 `enable_gaussian` 时点 (314,197) → 点 `tpl1786453689881.png` → 等 `tpl1786454119587.png` 渲染进度 → 点 `tpl1786454354649.png` → 等 `finish_wait_sec`(5s) → 截图。
- 参数：`run_texture_first / texture_timeout_sec / enable_gaussian / img_dir_name / dialog_wait_sec / dialog_timeout_sec / click_delay_sec / finish_wait_sec / mouse_safe_*`。

### 5) human_body_completion（人体补全）
- 动作：`touch((160,285))` 前置点击 → 点 `tpl1774270225446.png` → 点 `tpl1787753200875.png` →（测试版缺包处理下载弹窗）→ 点 `tpl1787753248187.png` → 在 “Select Head Front Image” 弹窗导入 `img/` 图片（同 AI重贴图策略）→ 可选 `enable_hd_geometry` 时点 (320,465) → 点 `tpl1787754024750.png`（立即生成）→ 点 `tpl1787754262949.png`（确认）→ 等 `tpl1787754339537.png`（创建人体模型进度）出现→消失 → 点 (140,720)（选择模型底座）→ 固定等 `base_wait_sec`(20s) → 点 `tpl1787755269508.png`（预览）→ 等 `tpl1787755313908.png`（AI人体补全进度）出现→消失 → 点 `tpl1787755544549.png`（应用）→ 截图。
- 参数：`timeout_sec / base_wait_sec / enable_hd_geometry / skip_trip_model / img_dir_name / dialog_timeout_sec / click_delay_sec / mouse_safe_*`。
- 高级参数 `skip_trip_model=true`（“不生成trip，直接生成人体补全模型”）：点击AI人体补全后直接点 `tpl1788787112505.png`（选择人体模型） → 点 (90,325) → 点 (140,720)（选择模型底座）→ 点 `tpl1787755269508.png`（预览）→ 等 `tpl1787755313908.png`（AI人体补全进度）出现→消失 → 点 `tpl1787755544549.png`（应用）→ 截图；跳过导入图片/立即生成/创建人体模型（trip）步骤。

### 6) return_home（返回首页）
- 动作：点 `tpl1772721639120.png` → 点 `tpl1772721648947.png` → 固定等 3 秒。返回 `ready_wait_sec=3`。

## 五、macOS 关键技术适配（重点，Windows 代码不能直接搬的地方）

| Windows 版 | macOS 版方案 |
| --- | --- |
| `airtest connect_device("Windows:///")` | 不用 Airtest；用 `reference/mac_poc/.../desktop_api.py` 的 `PyAutoGuiDesktop` |
| Airtest `Template(record_pos=…, resolution=…)` | PyAutoGUI `locateCenterOnScreen(path, confidence=0.9)` 直接给实际坐标；`record_pos` 不需要 |
| Airtest `wait/exists/snapshot/touch/sleep` | `wait_image / wait_image_gone / image_exists / screenshot / click_point / click_image / sleep` |
| `ctypes.windll.user32.SetCursorPos` | `pyautogui.moveTo(x, y)` |
| pywinauto 控制打开对话框（#32770、set_edit_text、type_keys） | **AppleScript System Events**：在打开对话框里 `Cmd+Shift+G` 弹出“前往文件夹”，输入路径，回车；多选用 `Cmd+A`。需 macOS「辅助功能」权限 |
| `Application(backend="uia").start(exe)` + 窗口句柄 | 启动：`subprocess` / `open -a "CrealityScan"`（或 `osascript`）；激活前台：`osascript -e 'tell application "CrealityScan" to activate'` |
| `window.maximize() / set_focus()`（pywinauto） | macOS 无窗口句柄方案，采用 **“运行前手动把 CrealityScan 放到前台”** 的约定（mac_poc 已验证），或用 AppleScript `activate` |
| `psutil` 进程管理 / `app.kill()` | 同样用 psutil；正常退出用 `osascript -e 'tell app "CrealityScan" to quit'`，超时后 `kill` |
| Ctrl 快捷键（`type_keys("^a")` 全选） | `Cmd+A`（`pyautogui.hotkey("command","a")`） |
| `%LOCALAPPDATA%\Creality\CrealityScan\Logs` | macOS 默认日志/数据目录需**在真机确认**（常见 `~/Library/Logs/Creality/CrealityScan`、`~/Library/Application Support/Creality/CrealityScan`），并做成可配置（`--log-dir`、`--extensions-dir`） |
| `%LOCALAPPDATA%\Creality\CrealityScan\Extensions\<pkg>\version.txt` | 同上，做成可配置默认值 |

**固定坐标与分辨率（必须处理）**：
- 模板图匹配（`locateCenterOnScreen`）返回真实屏幕坐标，**无需缩放**；
- 但代码里的**固定坐标点击**（如 `(160,285)`、质量选项 `(70/180,220)`、`(314,197)`、`(320,465)`、`(140,720)`、关窗确认等）是 **1920×1080 屏幕**的绝对坐标。Mac 上要么：(a) 按 `实际分辨率/1920` 与 `/1080` 做线性缩放；要么 (b) 在真机上改为模板匹配/重新采集坐标。**不要盲目沿用固定坐标**，否则在非 1080p 屏上会点错。
- 建议 Mac 版增加 `--expected-resolution` 检查（mac_poc 的 `check_environment` 已有）。

**权限**：
- 给 Terminal/Python 授予「屏幕录制」权限（否则截图/找图全黑）和「辅助功能」权限（否则 AppleScript 无法控制键盘/对话框）。
- 首次运行时在 系统设置 → 隐私与安全性 中授权。

## 七、验收标准（Mac 版必须满足）

1. **代码可导入**：6 个步骤模块、app_manager、file_dialog、report 都能在 macOS Python 3.10+ 导入，且暴露 `run(ctx, params)` 签名（不要求在导入时装 Airtest）。
2. **单元测试（不依赖硬件/真机）**，至少覆盖：
   - 工程集解析与双副本工作副本规划（含磁盘不足、禁止覆盖、输出目录不能位于工程集内）；
   - 导入成功日志判定（`OB_SCAN_MESSAGE_ID_PROJECT_IMPORT_SUCCESS` 或 `i proj progress 1.000000` 任一命中、超时报错）；
   - 下载进度 `Download progress: xx%` 解析；
   - 对比表生成（截图并排、缺失标记、包版本号），可用 `--test-only` 生成的最小产物验证；
   - 退出码与参数校验。
3. **真机冒烟（发布版→测试版，至少一种后处理）**：完整跑通 工作副本→启动→导入→后处理→返回首页→关闭→对比表，产物齐全（`release/ test/ 运行日志.txt 对比表`）。

## 八、注意事项 / 边界（不要臆测、不要省）

- **不要臆测未提供的变换**：模板图是 Windows 1920×1080 的界面裁剪，PyAutoGUI 用 `confidence` 找图；某模板在 Mac 版界面上匹配失败时，**必须在 Mac 上重新截图采集新模板**，而不是用缩放硬凑。
- **不要臆测 macOS 路径**：日志目录、Extensions 下载包目录、`CrealityScan.app` 的具体安装位置，以真机实测为准，做成可配置参数并提供默认探测。
- **版本顺序与隔离不可破坏**：发布版→测试版串行、双副本隔离、源工程只读，是产品的核心约束。
- **每个等待都要有上限与心跳**：导入/下载/进度条全部带超时，30s 打一次心跳日志。
- **截图时机**：必须在“鼠标已移开控件”后再截，保证无 hover 高亮。
- **GUI 可选**：Mac 版先交付稳定可靠的 CLI（Qt GUI 可不做，或后续再做）；若做 GUI，不得改变 CLI 合同与业务流程。
- **性能**：长后处理（高斯 15 分钟级）以“正确等待+可诊断”优先，不追求加速；轮询间隔参考 Windows 版（进度条 2s、导入 0.2s、下载 2s）。
