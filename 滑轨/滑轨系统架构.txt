根据代码分析，滑轨系统的架构如下：

┌─────────────────────────────────────────────────────────────────────┐
│                      滑轨控制系统架构                                │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  [其他工具 64位Python]  ────  motion_client.py  ────►  :5000        │
│                                             (Socket客户端)           │
│                                                                     │
│                                           ◄──────────  motion_service.py │
│                                                        (Socket服务端) │
│                                                               (32位)  │
│                                                                     │
│                                           er.py │
│                      滑轨控制系统架构                                │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  [其他工具 64位Python]  ────  motion_clien
               ◄──────────  zmotion_controller.py │
│                                                        (DLL封装)     │
│                                                                     │
│                                           ◄──────────  zauxdll.dll  │
│                                                        (正运动SDK)   │
│
│                                           ◄──────────  ECI1308控制器  │
└─────────────────────────────────────────────────────────────────────┘

需要提取的文件：
────────┼────────────┼──────────────────────────────────────┤
│ motion_client.py      │ 客户端     │ 64位Python │ 核心提取文件，其他工具直接import使用 │
├───────────────────────┼────────────┼────────────┼──────────────────────────────────────┤
│ motion_service.py     │ 服务端     │ 32位Python │ 需要单独部署在32位环境               │
├───────────────────────┼────────────┼────────────┼──────────────────────────────────────┤
│ zmotion_controller.py │ 控制器封装 │ 32位P                │
├───────────────────────┼────────────┼────────────┼──────────────────────────────────────┤
│ zauxdll.dll           │ SDK动态库  │ -          │ 需要和service一起部署                │
└───────────────────────┴────────────┴──────────────────────┘

使用方式：

# 其他工具中
from motion_client import MotionClient

client = MotionClient()
client.connect()
client.lift_up_duration(2)  # 上升2秒
client.lift_down_duration(2)  # 下降2秒
client.disconnect()

注意：服务端 (motion_service.py + zmotion_controller.py + zauxdll.dll) 需要：
1. 运行在32位Python环境
2. 通过32位Python启动 motion_service.py
3. 服务启动后客户端即可连接使用
