本次重设计做了什么

  • 按语义分组：拆成「通用超时」与「当前对比类型专属选项」两组，结束三个超时 + 三个开关挤在一行的混乱。
  • 专属参数按需显示：只有选中 AI重贴图 / 人体补全 时才显示对应专属组，贴图与高斯渲染显示一行安静提示，去掉禁用态的视觉噪音。
  • 标签精简：去掉复选框前缀的重复类型名（「AI重贴图开启高斯渲染」→「开启高斯渲染」），类型身份交给组标题。
  • 列对齐：标签/数值/单位三列对齐，与上方表单的 94px 标签节奏一致，扫读更快。
  • 主超时标签自适应：随对比类型切换显示「贴图超时 / 高斯渲染超时 / AI重贴图超时 / 人体补全超时」，语义不再含糊。
  • 未改任何参数名、默认值（90/120/20/90/20）与启用逻辑——与现版本行为完全一致。
